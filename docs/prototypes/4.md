# Prototype 4 — types, introductions, resolvers

**Status:** in progress. P3 step 2 shipped cream constructors (Circle, Segment, Line, Rect, Offset) on the same insert pipeline. P4 pulls those **off the palette** and rebuilds Point and Distance so picks bind to source without per-kind host switches.

## Charter

Space commands: **Point** and **Distance** only. `circle` / `segment` / `line` / `rect` stay valid in files you type; they are not Space verbs until pick/insert is solid.

**Types, not verbs.** A Point is still a Point whether it is free `editPoint`, an existing name, or `lineIntersection`. Those are **introductions**. Each type has one **slot resolver** (priority list). Distance’s first param is the union `point | line` (crossing counts as a point).

**Distance is the measurement verb.** Empty / point / crossing → `editDistanceToPoint` (ring). One cream line or offset handle → `editOffsetFromLine` (dashed parallel). No cream `offsetLine` in `group()`. No Offset command.

**Measurement vs visualization** stays: editors write literals; constructors do not. Do not snapshot a constructor into a number.

## Pass

- Point: empty → `editPoint`; crossing → `lineIntersection`; named point → no-op.
- Distance: union `from` then Length (type, click-measure, or reuse a named numeric widget). One write per completed verb.
- Hover preview (ring vs parallel) before click. Esc drops pending binds.
- Distance-to-line / crossings bind scene `segment`/`line` by injected construction **site**; inline group elements hoist to a `const` in the same write.
- euclid2 and sdf2: Point + Distance. No cream commands. euclid3 / sdf field: still none.

## Fail (stop)

- Cream verbs back on Space in this slice.
- Emitting `offsetLine(...)` into the group return for Distance-to-line.
- Snapshotting a cream radius/length into a literal.
- Per-tool `if (tool.id === …)` pick ladders in the host; resolvers own hits.
- Treating an offset gizmo as Length reuse while `from` is still empty (it is a line).

## Out of scope

- Circle, Segment, Line, Rect palette verbs (same resolvers, later)
- `editPointOnSegment`
- Constraints, 3D insert
