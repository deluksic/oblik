# Prototype 9 — figure: paint and style

**Status:** building. Euclid2 stays the sketch. A `figure` scene is a **parallel product** that reuses the same functions (`mountingPlateLayout()`, …). `style` and `paint` are constructors on the tape — stamped ids, inspect, insert in the focused function. Export is later.

## Why

Intent: **domain tools are views.** One library, two scene types. Euclid2 default-draws every traced geom. A figure starts empty and only publication strokes show, on cream paper.

Import-twice is the point: the figure file calls the same helper the euclid2 scene calls. It is not a live overlay of one tape.

```ts
const hole = style({ stroke: "#1c1917", width: 1.2, fill: "none" });

build() {
  const plate = mountingPlateLayout();
  paint(plate.drill, hole);
  paint(plate.hBottom, dash);
}
```

P8 mention/return is how the figure names geometry. Paint whatever the **focused function** can refer to (`plate.drill` in figure `build()`, `hLeft` after a dive into the helper). A private local has no name here — dive or Add to return. Do not ink by uuid.

## Locked (this slice)

**`kind: "figure"`** is a `Scene` union member. Same `defineScene({ kind, title, camera?, paper?, frame?, build })`. Filename stem is the catalog id.

**`style(spec, id?)` and `paint(geom, style, id?)` are `$site` constructors.** `dof: []` (not numeric-editable). Stamp, analyze, and `insertCall` treat them like `segment`. A top-level `const ink = style({...})` outside `build()` runs with no eval ctx and is an untraced value — that is allowed. Inside `build()`, both sit on the tape.

Spec: `stroke`, `fill`, `width`, `dash`, `point` (`"dot"` | `"open"` | `"none"`). `paint` walks branded `$node` geom in its first argument (a bag is fine). Last paint in tape order wins per `id:occ`.

**Deep selection is P8.** Select is scope. Mute dims other invocations. Space in a figure is a **style palette**, not Point/Circle. Click nameable geom → `const ink = paint(expr, style({...}), id)` in the focused function. If `mentionPrint` has no name, refuse (dive or Add to return).

**Onion** is unpainted construction, so you can still click, inspect, and dive. Painted geom draws with the style. No construction handles in this cut.

**Optional `frame: { width, height }`** is a world-unit artboard, letterboxed in the pane (cream or white). Omit it and the paper fills the view.

**Colocation cannot be prevented and might be OK.** A helper may `paint` inside itself (a TikZ `pic`). Euclid2 skips `style` / `paint` nodes. A figure draws them.

## Pass / fail

**Pass scene.** `?scene=plate-figure` — same `mountingPlateLayout()` as Mounting plate. Paints returned fields (`drill`, `origin`, `opp`, `hBottom`). Outline segments the helper does not return stay onioned until you dive and paint them in the layout file.

**Fail:** `{ style }` on `circle()`; a uuid sheet; Space inserting `point()` into the figure file; treating `paint` as an unmarked side-effect; default-drawing the whole tape as publication ink.

## Not this prototype

- SVG export, labels, TeX, arrow caps, images
- Construction handles / Point-Circle tools in the figure
- Un-paint as a tool — edit the file
- `{ style }` on constructors; reviving the uuid sheet
- Fusion / extrude
