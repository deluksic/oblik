# Prototype 9 — figure: paint and style

**Status:** building. Euclid2 stays the sketch. A `figure` scene is a **parallel product** that reuses the same helpers. `paint` is a tape constructor. Brush settings are a floating dock (stroke, fill, width, dash). Export is later.

## Interaction (this cut)

Idle **select** hits **ink** (`paint` nodes). Space is **Brush** and **Eraser**, both sticky until Esc. Hold **Shift** to see and pick construction (onion). Ink still draws on top while Shift is held, so a new stroke is visible before you let go. Hover/selection halos: [chrome.md](../chrome.md).

| Hit         | Brush                             | Eraser                       |
| ----------- | --------------------------------- | ---------------------------- |
| Idle ink    | **Replace** that paint’s look     | **Remove** that `paint(...)` |
| Shift onion | **Add** a new `paint` on the geom | No-op                        |

Hover onion with Brush **previews** the current dock settings, and only on geom this scope can name. Private construction stays onioned — no preview, no click. Stroke color is for points and lines. Fill is for regions (and circles). Regions use both the line look and the fill. Width and solid/dash/dot apply to strokes and to a region’s outline. Settings stay on the tool; they are not a Space list.

Stacking two strokes on one line: Shift+brush twice on the geom. Clicking existing ink with Brush restyles that object.

P8 still holds: select is scope; paint only names the focused function can refer to; dive or Add to return otherwise.

## Locked

**`kind: "figure"`** with optional `frame` / `paper` / `camera`.

**`paint(geom, look, id)`** is a `$site` constructor. Each call is its own ink object, drawn in tape order. **Look** is a plain object, or a `style()` value when the look is shared. Brush writes the object.

Onion is a hold-to-see overlay, not the default page. First ink needs Shift.

## Pass / fail

**Pass scene.** `?scene=plate-figure` — same `mountingPlateLayout()`. Idle page is the paints only. Shift shows the plate construction under the ink.

**Fail:** Space listing styles; last-wins collapsing two paints; onion as the default view; eraser deleting geom; `{ style }` on `circle()`; wrapping every paint in `style()`.
