# Prototype 11 — incremental evaluation: site memoization + user `memo()` + pick prefilter

**Status:** building. Every draft tick and every HMR edit used to re-run the entire scene `build()` from scratch, with `reuseUnchangedTrace` deep-comparing every node afterwards just to restore object identity. P11 adds a cache that manufactures identity at the leaf frontier and lets it propagate downstream by argument references — a dependency frontier with no graph, no dirty flags, and no content hashing.

## How it works

Scene code has exactly one way to say "this depends on that": passing a value as an argument. The memo exploits it. Each stamped constructor call is keyed `${id}:${occ}` (site id × dynamic call occurrence). On a call, the raw args minus the trailing id plus the site's own draft row form a **fingerprint**; if it equals the previous eval's fingerprint, the cached call replays — the tape node is re-pushed and the *previous eval's value object* is returned. Downstream constructors receive the same branded objects as last time, so their fingerprint compare hits on `===` identity, O(1) per dependency edge. Changed nodes build fresh objects; dependents see new pointers and recompute. Upstream hits guarantee same-object ⇒ same-value (values are immutable by convention), so identity propagation is sound without ever comparing geometry payloads.

`reuseUnchangedTrace` stays as a safety net; its per-element compare now short-circuits on identical objects, so a fully-cached eval pays nothing for it.

**User `memo(fn)`** is the same machinery for users' own expensive pure computations: `const layout = memo((n, r) => expensiveGrid(n, r))`. Entries are keyed by per-eval call occurrence; a hit returns the previous result object so identity flows into downstream constructors. The store is a WeakMap keyed on the function object — an HMR re-import of the defining module yields a fresh fn and full invalidation for free.

**Pick prefilter** (`euclid2/pick.ts`): since nodes are identity-stable now, each node's AABB is computed once into a `WeakMap<TraceNode, Aabb>` and reused; `hitsNear` and the snap scans cull nodes whose box is out of reach of the pick radius before any distance math. Lines are unbounded and never culled; rank/sort is untouched.

## Interaction (this cut)

The **Eval stats chip** toggle in Settings shows a chip on the euclid2 pane: `{ms}ms · {built} built · {hits} cached` per world eval. `?scene=cache-lab` is the proof scene: a 100-point loop grid, a memoized heavy layout feeding a polygon, an independent region → roundOffset → diff CSG chain, and one free bead. Dragging the bead rebuilds only the bead and its marker — `built` stays ~2 with flat eval time while the grid, layout, and chain all replay from cache.

Per-scene-module memos live in the panes, keyed on the scene module object: identical across draft ticks, replaced exactly when HMR re-imports the source — invalidation needs no bookkeeping.

## Locked

- **`build()` and `memo()` fns are deterministic**; produced values are treated immutable. A value that mutates between evals will serve stale hits.
- **Occurrence ordering must be stable**: entries are keyed by call occurrence, so inserting a call before existing ones shifts occs and misses the cache (correct, just cold — same limitation as trace reuse today). Loop count changes shift occs the same way.
- **Unbranded/complex args fall back to uncached construction, never wrong values**: fingerprints compare primitives by value, branded geom by identity only, plain objects/arrays elementwise to depth 4, anything else (class instances, Maps, deeper) as a miss. A miss is never wrong, just uncached.
- **Sliders are never cached** — they return bare numbers, so they always rebuild (O(1) work, uncounted in stats).
- **Cache is per scene module; ghost/tool draft evals pass through uncached** (their throwaway ctx has no memo), so they never poison or prune the live memo.

## Pass / fail

**Pass.** Second eval of an unchanged scene: `built 0`, every node value `===` the previous eval. Drag one point in a chain: that point and its dependents rebuild, independent siblings hit, values stay correct. Drag and revert to the original values: values correct again (frontier rebuilds once — a draft tick overwrites the single entry per key; `reuseUnchangedTrace` restores node identity at the pane level). `build()` throws mid-scene: cache untouched, next clean eval hits fully. Loop shrinks: dead occs swept after the successful eval, survivors hit. `memo(fn)`: hits by args value, misses when a branded arg's identity changes, invalidated by a fresh fn object (HMR). cache-lab drag: flat ms, `built` ~2.

**Fail:** a dependency graph; dirty flags; caching across scene modules or across ghost evals; comparing geometry payloads to decide a hit; serving a stale value after a fingerprint mismatch.

## Performance

The hit path is a Map lookup plus a fingerprint compare that is O(args), not O(geometry) — branded args cost one `===` each. Sweep after each successful eval prunes entries whose occurrence no longer exists; entries live in one Map per scene module. The pick prefilter trades one WeakMap hit per node per pick scan for skipping tessellation/SDF distance work on out-of-reach fills.

## Not this prototype

- Skipping `build()` JS execution itself (code reruns; data construction is memoized)
- A dependency graph, dirty propagation, or persistent incremental state across HMR
- Caching ghost/tool draft evals or the figure pane's paint path
- Spatial index beyond the AABB prefilter; worker offloading; TypeGPU
