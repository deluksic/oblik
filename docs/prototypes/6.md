# Prototype 6 — oblik: tape, draft, SVG

**Status:** open. Greenfield next to the P5 paper app (`packages/oblik`, `apps/demo`). Old `@design-scenes/*` stays until we migrate on purpose.

P5 proved the **look** (constructors on disk, handles from literals, Space as a command). P6 is the **runtime**: one package, Solid as the session, no hosts/plugins, no 3D/SDF in this cut.

## Why

The monorepo split (shell ↛ geom, hosts pushing inspect, three catalogs, `beginGeomFrame`, `withoutWidgets`, HMR swallow, `{ style }` on calls) was an accidental plugin platform. `session.ts` (~1600) and `insert-editor.ts` (~900) re-evaluate `scene()` in the TypeScript AST because the live graph was not the source of truth for tools.

## Locked

**Product.** Intent stays. TypeScript scene is the document. 2D only in this prototype. Scene types later via a **discriminated union**, not a host registry.

**Package.** Unscoped `oblik` (scope when we publish). `geom/` is a folder. Demo app `oblik-demo`. Scene type name: `"euclid2"`.

**Module.** `export default defineScene({ kind, title, camera?, build })`. No magic `export const title` / `export function scene`. Filename stem is the id.

**Eval vs view.**

```ts
evaluate(mod, { draft, annotations }): { value, trace }
```

- Constructors return values. Nested `evaluate` does not leak a tape. `emit` copies selected child nodes (same ids) onto the current tape.
- Default: every traced node is **visible**. Deviations are a sparse **sheet** keyed by uuid (not in this slice).
- `draft` is uncommitted literals (`Map<id, number[]>`), not a UI overlay. Solid memo: `evaluate(mod, { draft })`. rAF/SVG only paints.
- Scene type interprets `(kind, editable, value)` → stroke / gizmos / pick. Unknown kinds: skip.

**Identity.** Trailing call arg is **only** the id string: `circle(A, 2.5, "o_ab12")`. Plugin stamps missing ids onto disk. `editable` / `bind` / position live in a **virtual annotations** module derived by `analyze(source)` — same analyzer for tests and Vite. Join key is the uuid, never `file:line:column`.

**`$site` on the function.** `circle[$site] = { dof: [1] }`. Plugin imports constructors; no parallel name table. Euclid2 **pixels** stay next to SVG components, keyed by `value.kind`.

**Context.** One `current` eval ctx; save/restore in `finally` (not a stack array).

**HMR.** Always apply the new module. Keep `draft` until that module’s `build()` has run and produced a trace, then drop the override. Do not compare literals to disk. Annotations HMR does not drop draft. Camera is a signal. No self-write swallow.

**Insert.** Fourth source job: `{ file, from, bind?, args: Expr[] }`. Palette (euclid2) ends at `Expr` (`num` | `ref` | `call`). Space: Point, Circle, Line, Segment. Snap reads the live tape.

**SVG.** Euclid2 is Solid + SVG. Camera is a **group transform** over aspect-correct NDC `viewBox`, not world units in `viewBox`. Y-up via `scale(1,-1)`. Handles use **relative** pointer Δ (no jump-to-cursor). Canvas is a later swap if the tape is too large.

**Traces.** `segment(a,b)` is **one** node. End caps are euclid2 drawing. User `point()` is its own node. `geom/` never calls traced constructors (`constructDepth` is not the model).

**Stack.** Keep `Error.stack` for caller frames. Leaf site from the annotation map (disk). `/__map-stack` stays for callers against Vite’s transform.

**Not this slice.** Layout-as-kind, `emit` filters, named palettes, style sheet UI, migrating paper, gliders, offset handle, inspect.

## Honesty (what we refuse to rebuild)

- AST mini-interpreter of `build()` for snap (`evalDerivedScenePoints`). Snap reads the live tape.
- Dual geom/gizmo frames and `withoutWidgets` publish maps.
- Inspect pushed from a canvas rAF through snapshot keys.
- `{ style }` / `__annotations__` on the constructor.

**Still inherent:** stamp AST, patch by id, HMR module swap, loop `occ`, NDC camera, `Expr` printing (euclid2, later).

## First slice (pass / fail)

Hand-typed shelf-like scene in `apps/demo`:

- `point` / `line` / `circle` / `segment` with trailing ids
- SVG shows strokes; editable point + radius handles
- Drag is relative; release patches literals; draft holds until the new module’s `build()` has run
- Space inserts Point / Circle / Line / Segment via `Expr` (snap from the tape)
- Missing id: plugin stamps the file

**Fail:** handles jump to the cursor; `segment` emits endpoint traces; draft cleared on annotations HMR while the old module is still live; `file:line:column` as the write key.
