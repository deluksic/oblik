# Prototype 5 — construction graph on 2D paper

**Status:** closed (learned). The app kicker is Prototype 5. P4 stays the pick-binding experiment; this was the 2D product: tools emit constructors, handles come from annotated literals, multi-use is **named fields on a product**.

## Went well

**The disk looks like the graph.** Space writes `point`, `circle`, `line`, `segment`, `offsetLine`, `slider`, `dist`, `signedDist`, `lineIntersection`, `circleLineIntersection`. You can read the file and see the figure. That was the whole bet after P4’s dashed-ring Distance.

**Named fields beat a uniform length protocol.** Circle exposes `.radius`, Offset `{ line, distance }`. Length-slot click writes `shelf.distance` or `reach.radius` or a slider name — not `[LENGTH]` / `.valueOf`. Same ink, two slots: Length vs LineLike is which slot is open. Teaching cost remains; the graph stays honest.

**Potential vs actual is an annotator fact.** `circle(A, 2.5)` gets a ring; `circle(lamp, dist(lamp, P))` does not. Disk never grows `{ editable: true }` on a computation. Hosts spawn gizmos from `editable` + finite placement. geom stayed gizmo-free.

**Misses are NaN.** Shrink reach until it misses the shelf: P / beam / Q / segment vanish; A, B, lamp, `1.8`, `2.5` keep handles. Restore the literal, same `+1` branch returns. No `null`, no hopping.

**Three catalogs, not a plugin platform.** Call sites (annotator / patch), Space tools (palette + draft), handle ink. Shell still does not import geom. Click / compile / preview share resolvers in `session.ts` because they have to.

**The docked preview is the command.** `const <name> = circle(<center>, <radius>)` is the UI. Tab cycles slots. Invalid names get a squiggly and block commit; empty names auto-bind (`p`, `p2`). Duplicates of a *valid* identifier suffix. Point takes typed x/y and still accepts a click for the empty axis. Offset keeps signed distance (ghost had been clamping negatives — compile did not).

**Old scenes survived.** plate / beam / ring still speak `edit*`. P5 insert does not emit them. sdf2 stayed Point + Distance.

**Shelf is constructible from Space.** [?scene=shelf](http://127.0.0.1:43117/?scene=shelf) matches the worked example: handles on A, B, lamp, shelf distance, reach radius; not on P, Q, beam, cellar.

## Needs improvement

**`session.ts` is the whole tool runtime.** Palette, ghost, and catalogs split out; click / compile / preview did not. ~1500 lines, no host tests. Session updates that drop `name` / `naming` / `open` were real bugs. Ghost `Math.max(0.05, n)` lied about signed offset. This will keep biting every new verb.

**One overlay input.** Multi-slot tools are Tab, not two fields. Fine for a prototype; cramped once Line wants typed endpoints the way Point wants typed x/y.

**Same ink, two meanings.** Offset in a Length slot vs LineLike slot is correct and easy to mis-click. The preview says which slot is live; the canvas stroke does not.

**Two languages on disk.** Catalog demos are still `editPoint` / `editDistanceToPoint`. Space writes constructors. New-scene starters and muscle memory disagree. Migrating those files was explicitly out; leaving them this long makes P5 look unfinished in the nav.

**Chrome lagged the tools.** Global `#error` moved every canvas. Overlay covered the status strip. Status echoed the prompt hint. Cursor, reserved strip, and “prompt owns instructions” landed late. Right place was always per-pane; we found it by shoving.

**Still missing from a 2D graph.** Gliders / point-on-line, foot, midpoint, tangent, rect. Offset of a segment is still an infinite parallel (no chord length). `+1`/`-1` is frozen from the click and invisible. Line has no Length field (correct, but Length-click on `ground` does nothing). sdf2 / euclid3 Space insert unchanged.

**Hygiene.** `hosts` `tsc --noEmit` still fails on `.ts` imports. `pnpm lint` is oxlint on old Node. No tests for tool compile. Live scratch (`shared-loop.scene.ts`) is not the catalog.

## Locked decisions

- Disk is the graph. Tools write `point`, `circle`, `line`, `segment`, `offsetLine`, `slider`, `dist`, `signedDist`, `lineIntersection`, `circleLineIntersection`.
- No `[LENGTH]`, no `.valueOf`. Offset is `{ line, distance }`. Circle is a `Circle` (`.center`, `.radius`). Tools have a **per-kind field table**.
- Shared number: Slider tool, then Length-slot click emits the **name**. Bare `const r = 1.8` is frozen; do not chase.
- Call-site annotator injects `__annotations__: { file, at, editable }` on the running module (disk unchanged). Overwrite that key and warn. Public `{ editable: false }` freezes a literal.
- `editable: true` only when that call’s DOF args are numeric literals (including `-1.2`).
- Misses are **NaN** (point `x,y` or a length), not `null`. Do not draw; omit gizmos whose placement is not finite. Upstream literals keep handles.
- `+1` / `-1` on intersections is a frozen branch from the click, not a handle.
- geom stays gizmo-free. Host binds handles after eval from `editable` + kind.
- Constraints out. Two-way coincidence is a fail if we fake it.

## Why not P4

| | P4 | P5 |
| --- | --- | --- |
| Space | Point, Distance (+ Line leftover) | Point, Circle, Line, Segment, Offset, Slider |
| Insert | `editPoint`, `editDistanceToPoint`, `editOffsetFromLine` | constructors + `slider` |
| Circle on paper | dashed ring only | `circle(...)` stroke; ring only if radius literal is owned here |
| Offset | number widget, `offsetLine` silent | `{ line, distance }`, line is drawn |
| Identity | `{ file, at }` on `edit*` / geom | same, nested under `__annotations__` |
| Length reuse | named `editDistance*` / offset widget | `name`, `other.radius`, `other.distance`, `dist` / `signedDist` |

Existing catalog scenes (`editPoint` / `editDistanceToPoint` in plate, beam, ring, …) keep working. P5 insert path does not emit `edit*`. Do not migrate those files in this prototype unless a change forces it (`offsetLine` return type, `lineIntersection` NaN).

## Architecture

```
disk scene  --(Vite pre-transform / call-site annotator)--> running module
running module --(pure geom + slider in euclid2)--> values with site + editable
host --(kind + editable + finite placement)--> gizmos
gizmo drag --(patch-widget at site, numeric literals)--> disk
```

**Product fields** (what a kind exposes to slots and gizmos):

| kind | draw | Length slot writes | LineLike slot | Point slot | gizmo if editable |
| --- | --- | --- | --- | --- | --- |
| Point | dot | — (or `dist`/`signedDist` if origin bound) | — | name / itself | point handle |
| Circle | stroke | `.radius` | — | `.center` | radius ring at center |
| Line | stroke | — | itself | — | none (drag endpoints) |
| Segment | stroke | skip in P5 (or chord later) | itself | `.a` / `.b` | none |
| Offset | `.line` | `.distance` | `.line` | — | offset handle on `.line` |
| slider | HUD | the name | — | — | number slider |

Name lists that used to be copied into palette / annotator / patcher live in the catalogs in [layout.md](../layout.md#catalogs).

## Phase 5 — tools

`packages/hosts/src/tools/session.ts`, `packages/hosts/src/tools/catalog.ts`, `paper2.ts`.

Space (euclid2 only): **Point, Circle, Line, Segment, Offset, Slider**. Remove Distance from the insert palette (leave `edit*` in files). sdf2: unchanged this prototype.

Resolvers (P4 shape, new compile):

**Point** — empty → `point(x,y)`; named Point → reuse; L∩L → `lineIntersection`; C∩L → `circleLineIntersection(..., ±1)` from click; Offset in a Point slot → miss (not a point).

**Circle** — Point slot, then Length: literal / measure → `circle(c, 2.4)`; Offset → `circle(c, shelf.distance)`; Circle → `circle(c, reach.radius)`; slider → `circle(c, r)`; Point → `circle(c, dist(c, q))`. Always emit `circle(...)`.

**Line / Segment** — two Points → `line(a,b)` / `segment(a,b)`.

**Offset** — LineLike slot (Line, Segment, `offset.line`), then Length (same introductions as Circle, Point → `signedDist`). Emit `const shelf = offsetLine(ground, 1.8)`. Further intersects use `shelf.line`.

**Slider** — type or click-measure → `const r = slider(1.8)`.

Compile patches import from `@design-scenes/geom` (and `slider` from euclid2). Docked preview shows the constructor, not `edit*`.

Hit tests: Length vs LineLike on the same Offset ink is **which slot is active**. Do not snapshot `dist` / `.distance` into a new literal.

**Pass:** Space-only construction of the shelf figure (below) without typing. Peek matches the disk column.

**Fail:** Distance command back on Space; `editCircle`; implicit coerce Circle → number.

## Phase 6 — acceptance scene

Add `apps/paper/src/scenes/shelf.scene.ts` (or build it only via Space in a new scene). Target disk:

```ts
const A = point(0, 0);
const B = point(6, 0.4);
const ground = line(A, B);
const shelf = offsetLine(ground, 1.8);
const reach = circle(A, 2.5);
const P = circleLineIntersection(reach, shelf.line, +1);
segment(A, P);
const lamp = point(2.2, 3.1);
const beam = circle(lamp, dist(lamp, P));
const Q = circleLineIntersection(beam, ground, +1);
line(P, Q);
const cellar = offsetLine(ground, -shelf.distance);
```

Manual checks:

- Handles: A, B, lamp, shelf distance, reach radius. Not P, Q, beam, cellar.
- Shrink reach until miss: P/beam/Q/segment/PQ vanish; five handles remain; restore `2.5` and the same `+1` root returns.
- Length-slot click shelf when placing cellar → `-shelf.distance`.
- Slider then `circle`/`offsetLine` reuse `r`; one HUD, no extra ring.
