# Prototype 2 — scene catalog and shell layouts

Built a scene catalog and a pane workspace: a file in `scenes/` is the registry, layouts are CSS grid areas named by scene id, view hosts plug in, libraries stay pure.

## Asked

Adding a scene had become a URL branch, a runner map, an HTML pane, CSS, an HMR `accept` list, and a widget-channel string. The charter was: a file in `apps/paper/src/scenes/` is enough for nav and `?scene=<id>`. Window layout is a shell concern. No `main.ts` branch, no `#pane-*` in `index.html`.

1. Add `scenes/hello.ts` with `scene()` and a `view`. Nav shows it. `?scene=hello` opens one pane.
2. A layout-only file of existing ids. Two panes; live drag from 2D still updates 3D.
3. Rose as three panes from a layout export.
4. Delete a scene file: it leaves the nav. Layouts that named it fail visibly.

Hosts plug in (`euclid2` / `euclid3` / `sdf` / `sdf2`). The shell must not import geometry. Layout files export string ids only. Widget channel = catalog id (`withoutWidgets(fn, "plate")` matches `plate.ts`).

## Learned

- Adding `scenes/hello.ts` is enough for nav + `?scene=hello`. No `main.ts` branch, no canvas ids in HTML.
- Layout-only files (`rose.ts`, `split.ts`, …) do not import pane modules. Live drag still updates the other panes via widget channels (`"plate"`, `"cylinder"`, `"profile"`).
- The shell does not import geometry.

**Widget write-back looked like a full app refresh.** The catalog fingerprint correctly ignored number patches, but Vite still HMR’d glob-loaded scene modules with no acceptor, so the client did `page reload`. Cameras reset. Fix: swallow HMR when the file still matches the write; `scene-loaders` accepts every scene path so a real editor save hot-swaps.

**Channels are still magic strings.** `withoutWidgets(fn, "plate")` must match the catalog id. Wrong channel silently collides on widget index 0.

**Cross-scene `hot.accept("./plate.ts")`** in mill/helix/rose is a second path besides the glob. Needed so `let readPlate = plateLayout` updates on a real save.

## Keep

- Gizmos stay out of domain libraries.
- Layout files must not import pane modules.
- Catalog HMR is not “the file changed.”
- Unmarked numbers are still not handles.
