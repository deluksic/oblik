# Prototype 7 — Loop, Region, and Csg2 on the euclid2 tape

**Status:** shipped (language). Loop / Region / Csg2 live in euclid2 (`packages/oblik`, `apps/demo`). Horizon (paper scene, palettes, Fusion) is still not this prototype. P9 is the view experiment that inks this tape.

P6 stays the running runtime. This charter is the memory for what we cut and what we locked.

## Why

A project-wide style sheet keyed by uuid failed for three reasons that are the same reason:

- Paint was not colocated with anything a human reads.
- Copying or duplicating a scene did not take the look along (ids restamp; the sidecar does not).
- Helpers cannot be reused across views: one id is the right join for _editing a literal_ and the wrong join for _how this scene paints_.

Colocating `{ style }` on `circle()` fixes copy-paste for a file that _is_ the drawing and poisons reuse the moment a second system looks at the same code. Ignoring extra metadata at runtime does not help the reader: the call still accretes `{ style, mill, tex }`.

**Style is a view. Construction is a tape.** Euclid2 stays the sketch (literals, sliders, snap, insert, default draw, jump-to-source). Publication — fills, TeX, line weights, arrow caps, empty white paper — is a later scene type looking at that tape. Fusion-like solid / sheet-metal is another type looking at the same **curves and regions**, not at paper swatches.

The missing object on the tape is not a color. It is a **region**: a declared cheese whose outer and holes are **loops** — each loop is a closed cycle of spans on existing carriers (or a full circle). Paper will fill it. Solid will extrude it. If P7 only invents a paper-local hatch, every later type reinvents the face.

Planar booleans are a second tape value, **Csg2**: union / diff / intersect of regions, disks, half-planes, offsets, and picks. Offset is a **leaf**, not a boolean op. Compile of Csg2 → Region[] is deferred; the renderer walks the tree with SVG luminance masks.

## Horizon (not P7)

Remember this; do not build it in this prototype.

### Paper (name TBD)

A new `Scene` union member. Start from an euclid2 scene. Empty white page, onion skin **on**. The paper document is **ink**, not geometry. Nothing is on the page until you ink it — the opposite of euclid2’s default-draw.

**Consume the tape, not a return bag.** `build()` returning `{ A, B, drill }` is a second API. The sketch already exposes every constructor site (id, bind, kind, value). Join ink by **id**. Binds are default label text, not keys. Result drilling is how you get “the figure can only name what the scene remembered to export.”

**Onion skin is a lightbox.** Ghost the whole sketch (points _and_ lines together). Filtering is **pick-only**, not visibility: a stroke applicator must not take a point click (fall through to the line); a point applicator still prefers the point. You need both ghosts to read the drawing.

**Applicator, not constructor.** Space opens a style palette (provided + user chips: color, width, dash, double/triple, point shape/outline, arrow **caps** on finite strokes). Click a compatible ghost → that id is inked with the current named swatch. Select on a ghost inks the default for that kind. Eyedropper / erase. No insert, no handles — moving `lamp` happens in the sketch; paper rides the same ids.

**Named swatches, not a uuid sidecar.** The paper file stores `id → swatch name` (and paper presets: white/cream, blank/dots/lines/grid). Changing `textbook.emphasis` restyles every use. Palettes are modules you can `import`. Inline override is the exception.

**Sync.** New sketch geometry appears as ghosts, not auto-ink. Deleted sites leave orphan ink rows you delete. No declaration-sync compiler in v1; warn like today’s kind mismatch.

**Proving publication.** Shelf as a blog figure: cellar dashed, shelf heavy, lamp hollow, live `d(L,P)` label, onion off, export SVG without host chrome. If that SVG still needs the dark construction UI to be understandable, the type is not done.

**Code that GUIs cannot keep honest.** The paper is a function of a live tape (drag the sketch, the embed moves). One sketch, many papers (loop, steps, print vs post) without copying paths. Labels from values so captions cannot rot. `occ` / binds / kinds are structure, not groups you hope held. Clicks _write_ TypeScript (`ink("o_lamp", "textbook.point")`); they are not an opaque document.

Arrows are stroke **caps**, not extra objects. Infinite lines probably do not get caps (no finite end).

### Common language (curves → loops → regions → verbs)

Three layers so tools are not rewritten per purpose:

| Layer       | Holds                                                                                                                                                                     | Must not                                                                                |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| `geom/`     | Points; infinite lines; segments; circles; **spans** (a, b on an existing carrier); **loops** (closed cycle or full circle); **regions** (outer + holes); **Csg2** / pick | Pens, TeX, extrude depth, paper; extra segments/arcs whose only job is to feed a region |
| Tape        | Those values + id, bind, occ                                                                                                                                              | View-specific bags                                                                      |
| Scene types | Verbs on the same pick vocabulary: point, curve, region                                                                                                                   | A private `Path` type each                                                              |

**Declared cycle, not live-paint magic.** Fusion auto-finds sketch faces; identity is slippery and Git sees arrangement. Start with an **explicit** region (ordered curve refs, written by a tool into the sketch file). Arrangement that _proposes_ a cycle you commit can come later.

Infinite lines are not edges until a span names two points on them. Walking a circle is a span on that circle (`k` chooses which way), not a polyline and not a new `arc(` on disk. A full circle as a loop is the circle itself (zero vertices). Endpoints are the sketch’s points. Holes are inner loops.

The **region tool** is a shared authoring gesture (point, carrier, point, … until close). Paper’s last call is `fill`; solid’s is `extrude`. Same chain. P7 puts that gesture in **euclid2** so the artifact exists before a paper type needs it.

## P7 slice — Loop / Region / Csg2 in euclid2

**Locked in this slice:** `Loop` / `Region` / `Csg2` geom values, unmarked `along` and `fillet`, traced `region` / `diff` / `union` / `intersect` / `pick` / `roundOffset`, Space tools for Region, Round offset, and Fillet, muted fill on the euclid2 paper (shared `FillFace` for euclid2 and figure).

### Inputs

The **tool** is **point, carrier, point, carrier, …** until the next point is the start. Vertices are named points or **crossings** (insert hoists `lineIntersection` / `circleLineIntersection` / `circleCircleIntersection`). Each carrier click is a witness on a 1D thing that already exists — circle, segment, line, parallel — with an arrow **at the cursor**.

The region does **not** create geometry to name a carrier. Segments are treated as infinite supporting lines. Off the line: closest point, keep going.

Hand-typed:

```ts
const chord = segment(A, B, "o_ch");
region([A, chord, B, along(c, 1)], [], "o_slice");
region([A, ab, B, bc, C, ca], [[P, pq, Q, qp]], "o_frame");
region([bl, bottom, tr, right, br, top, tl, left], [drill, h1, h2, h3], "o_face");
diff(stock, [drill, slot], "o_face");
union([head, tunic, s0], "o_body");
intersect([stock, leftOf(split)], "o_keep");
pick(csg, probe, "o_island");
roundOffset(wedge, -gap, "o_one");
```

Constructors take **explicit arrays**. No rest args, no optional holes object, no `optsOrId`. Trailing site `id?` stays optional like `point` / `circle`.

`along` is unmarked (like `dist`): no trailing id, not a tape node. `fillet(A, r)` is an unmarked vertex witness. Only `region` / CSG / `pick` / `roundOffset` are traced. A hole is another **loop** — not a tape node and not a nested `region(`. A circle in the holes array is a full-circle loop.

**Not inputs:** polylines of free clicks, style, a traced `arc` site. Unbound strokes are not addressable; free clicks in a point slot are ignored. Crossings are vertices. The Region tool still writes a hole-free outer (`region([...], [], id)`); holes are declared in the call.

Pick follows the phase: point slot prefers points; **the start point has a very fat snap when the cycle can close**; carrier slot prefers the stroke/circle and does not let a coincident point steal. Fill pick is last (behind points and strokes). Scope: `scope.regions`, `snapRegion`, `resolveRegion`, `PlaceHit.region`.

### Witness-first (every carrier)

**Circle** — `along(c, k)` for a partial walk. Bare `c` as a loop item is a **full-circle** loop (zero vertices). Hover arrow is winding from the current point through the cursor. Tab flips `k` on the last circle.

**Segment or line** — bare ref, treated as infinite. The arrow is which way to leave the current point. Next point can be an end or short of it.

### Data format

```ts
type LoopEdge = { a: Vec2; b: Vec2; carrier: LineLike | Circle; k?: 1 | -1 };
type Loop = LoopEdge[] | Circle;
type Region = { kind: "region"; outer: Loop; holes: Loop[] };
type Csg2 = { kind: "csg2"; op: "union" | "diff" | "intersect"; of: readonly CsgOperand[] };
type Pick = { kind: "pick"; of: CsgOperand; at: Vec2 };
type Offset = { kind: "offset"; of: CsgOperand; d: number };
```

Disk: `region(cycle, holes, id?)`. Vertex slots accept `fillet(A, r)` (unmarked, like `along`). Geom stores projected vertices (closest point on the infinite line / circle). Close is implied (last carrier returns to the first point). `along`, `fillet`, and a hole loop are not `$site`. A hole that exits the outer, overlaps another hole, or nests in another hole NaNs the region. Contains is inside the outer and not inside any hole — not even-odd of overlapping loops. SVG for a declared region is `outer Z` plus each `hole Z` with `fill-rule="evenodd"`.

`roundOffset(face, d, id?)` takes a **Region**, not a CsgOperand. It is a Csg2 wrapping `{ kind: "offset"; of; d }` (unary union via `wrapCsg`). Membership is `sdf(of) − d`. Fillet writes into declared `region([...], [])` cycles; **do not fillet CSG / offset results**.

`pick(csg, p, id?)` is a tape node, not a Csg2 op. Compile of Csg2 → Region[] is later; until then the renderer walks the tree with nested SVG masks.

### Tool

Space → Region. Clicks: **point → carrier → point → carrier → …** until a point click is the start. Insert **only** the `region([...], [], id)` statement. Do not insert helper `segment`/`arc` lines. Tool id / verb is `"region"` (prefix `rg`). Ghost kind is `"region"`.

Space → Fillet. Clicks: **corner** (face under the pointer, then that face’s closest logical vertex) **→ length** (typed number, slider, `reach.radius`, parallel `.distance`, or rubber-band `dist(A, cursor)`). Writes `fillet(A, r)` **in that vertex slot**. Does not append a `const`. Re-fillet replaces `r`. `r === 0` unwraps to a sharp vertex. Too-large `r` ghosts empty (no clamp). Prefix `fil`. Only a declared `region([...], [])` has vertices to patch; `roundOffset` is a **Csg2** (a set) and cannot be filleted.

### Pass / fail

**Pass scene:** `apps/demo/src/scenes/pie.ts` — three `pointOnCircle` on one reach, radii as segments, `roundOffset(region([O, oa, A, along(reach, 1), B, ob], []), -gap)`.

**Fillet:** `apps/demo/src/scenes/fillet.ts` — one `r` on every `fillet(·, r)`: opposite corners, all-round + inset, adjacent overlap (vanishes past ~0.7), L-notch, sector rim/tip, fillet at a 180° origin (left sharp), clockwise square.

**Mounting plate:** `apps/demo/src/layout/mounting-plate.ts` — `region(..., [drill, h1, h2, h3], "o_face")`. Circular holes are loops, not CSG cutters.

**Stock-cutters:** `apps/demo/src/layout/stock-cutters.ts` — `diff` / `intersect` / `pick` of stock, drills, stadium slot, half-planes. A drill off the plate drops that hole; a slot that severs stays one CSG, `pick` follows the probe.

**Arcade:** `apps/demo/src/scenes/arcade.ts` — Pac-Man is `diff(disk, [mouth])`; the ghost is `diff(union([head, tunic, scallops]), [eyes])`.

**Pass:** disk shows the array cycle; drag a point or radius and the fill follows; a miss NaNs the region; stamp the **region** / CSG id only; pick the face (lowest precedence); inspect origin is the `region` / CSG site. On `?scene=fillet`, Space → Fillet, click a sharp corner of `mix`, click `r` → that array slot becomes `fillet(·, r)`.

**Fail:** extra `segment`/`arc` whose only purpose is to feed the region; polyline of the circle as the source of truth; CSS fill on the circle; sidecar; auto-faces with no `region(` on disk; rest-arg constructors; filleting a `diff` / `roundOffset`; compiling CSG with marching squares in this slice.

## Not this prototype

- Paper / figure scene, onion skin, palettes, embed SVG, TeX labels, applicator (figure is P9)
- Replacing or extending the P6 uuid style sheet (treat it as a failed experiment; do not grow it)
- Fusion / sheet-metal / extrude
- Computed arrangement, live-paint “click the well”
- Compile of Csg2 → Region[]; occupancy flood / marching squares for offset geometry
- `vector`, general `polyline`, slots as constructors (arcs-on-circles in a region are the fillet-shaped _edge_; `fillet(A, r)` is a vertex witness inside `region([...], [])`, not a second face)
- Chamfer; wrapping vertices while Region is still open; picking two edges instead of the corner
- Standalone decorative arrows; caps wait for paper stroke styles
- Standalone traced `arc` as its own tape node (a later Arc tool — P7 walks the circle via `along`, or names the circle as a full loop)
- Forcing `build()` to return a public bag for join keys

## Open (later)

- A validator that warns when a named point is far from its carrier (constructor still projects)
- Region tool writing holes; Minkowski offset of swiss cheese / split insets compiled to walks (union of islands)
- Compile Csg2 to Region[] for fillet / offset of boolean results

Already locked: `region(cycle, holes, id?)`; `diff(stock, cutters, id?)`; `union(operands, id?)`; `intersect(operands, id?)`; `pick(of, at, id?)`; `roundOffset(face, d, id?)`; unmarked `along(c, k)` on a partial circle walk; unmarked `fillet(A, r)` in a vertex slot; bare line/segment as infinite; a circle as a full-circle loop; points always named; closest-point not a refuse; fill last in pick; close-point first when the cycle can close; no extra `segment`/`arc` from the tool; Tab flips circle `k`; `Loop` is the cycle primitive (outer and holes); overlapping declared holes empty the region; `roundOffset` is a Csg2 leaf, not a declared walk, and cannot be filleted.

## Honesty

Do not rebuild Pathfinder, a second SVG scene type, or `{ style }` on constructors in order to “see a fill.” The fill in P7 is proof the **value** exists. The common language is the value.
